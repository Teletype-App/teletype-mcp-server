# Документация

Обзор проекта в корневом [README](../../README.md). В этой папке собраны справочные документы:

- [Справочник инструментов](TOOLS.md): все 17 инструментов, параметры, наборы и правила подтверждения
- [Рецепты](RECIPES.md): готовые промпты для утренних сводок, разбора очереди и аудита пометок
- [MCP-клиенты](CLIENTS.md): настройка Cursor, VS Code с Copilot, Codex, Claude Code, OpenCode, Antigravity CLI и других клиентов
- [Архитектура](ARCHITECTURE.md): путь запроса, архитектурные решения и границы безопасности
- [Результаты eval](EVAL_RESULTS.md): прогоны пяти комбинаций терминального клиента и модели, токены и оценка стоимости по API
- [Безопасность](SECURITY.md): как сообщать об уязвимостях приватно
- [Участие в разработке](CONTRIBUTING.md): локальная настройка, проверки и правила запросов на включение
